# Progetto HTML-CSS: Discord

### Continua sulla repository: htmlcss-discord

## Descrizione

Questo progetto realizza la struttura di una pagina web statica ispirata allo stile di Discord.

## Struttura principale

- **Header**: una barra superiore con tre sezioni (logo, navigazione con link e area login).
- **Main**: area centrale composta da più sezioni di varie dimensioni (small, medium, big), suddivise in container e blocchi inline che creano un layout flessibile e bilanciato. 
- **Footer**: sezione a piè di pagina con due colonne principali e una barra di navigazione inferiore. 

## Caratteristiche tecniche

- Utilizzo del Flexbox per il posizionamento e l'allineamento dei contenuti (sia in righe che colonne).
- Contenitori e sezioni con dimensioni variabili, definite tramite classi CSS (small-container, medium-container, big-container) per gestire l’altezza e larghezza degli elementi.
- Elementi come header, nav e footer con stili personalizzati per spaziatura e allineamento.
- Layout responsive semplice, basato su contenitori con larghezza fissa e margini.
